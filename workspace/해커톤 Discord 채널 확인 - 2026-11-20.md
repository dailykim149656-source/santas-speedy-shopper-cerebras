## TPS 상금과 아직 공개되지 않은 규칙

운영진이 확정한 상금은 총 **미화 5,000달러**다. X에서 자연 노출 수가 가장 높은 게시물 3개에 각 1,000달러, r/cerebras에서 추천 수가 가장 높은 게시물 1개에 1,000달러, Kimi K3.1 Pro를 Cerebras에서 실행해 가장 빠른 TPS를 내는 프롬프트에 1,000달러를 지급한다. 초기 경품으로 언급된 각인 Mac mini는 현금으로 바뀌었다. 두 번째 공지는 공식 X 게시물의 재게시와 댓글을 요청한 홍보 글이었다. [상금·일정 공지](https://discord.com/channels/1085960591052644463/1572277577429549216/1572296927314452523) · [현금 변경 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1572997808330645656) · [홍보 요청](https://discord.com/channels/1085960591052644463/1572277577429549216/1573052535269236866)

11월 19일 참가자가 출력 토큰을 어떤 시간으로 나누는지, 대기 시간과 입력 프롬프트 처리 시간을 제외하는지 물었다. 운영진은 세부 규칙을 기다리고 있다고 답했고, 같은 날 20:52에 후속 안내를 예고했다. 11월 20일 13:00에는 별도 지원 글에서 제출 위치, 프롬프트·모델 설정·원본 응답 첨부 여부, 참가자와 주최 측 중 누가 측정하는지를 물었다. 확인 시각까지 이 글의 댓글은 **0개**였다. 네 채널과 공식 가이드에서 TPS 산식, 최소 출력 길이, 반복 횟수, 제출 창구를 확정하는 안내는 찾지 못했다. 프롬프트 캐시 지원과 캐시 토큰의 분당 한도 반영 여부에도 운영진은 확인 중이라고 답했다. `max_tokens`를 기준으로 한도를 미리 차감하는지, 여러 에이전트의 처리량을 합산할 수 있는지에 대한 확정 답변도 찾지 못했다. ## 모델 접근과 개발 준비

- **접수 확인.** 사용자는 Cerebras Org ID 제출을 완료했다. 운영진은 접수 확인 이메일을 발송하지 않는다고 밝혔다. 개별 신청의 접수 여부를 확인해 달라는 지원 포럼 글도 댓글 0개였다. 팀원이 각자 독립적으로 모델에 접근하려면 각자 신청한다는 답변이 있었다. [확인 이메일 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1572849240760127509) · [지원 포럼 문의](https://discord.com/channels/1085960591052644463/1572281523518972047/threads/1573187028076593272) · [팀원별 신청 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1572872925290430525)
- **모델과 요금.** 대회용 모델 ID는 `moonshotai-kimi-k3.1-pro-trial`, 기본 URL은 `https://api.cerebras.ai/v1`이다. 추론 모드는 기본으로 꺼져 있고 `reasoning_effort`로 켤 수 있다. 운영진은 대회용 Kimi 이용 시 기존 크레딧을 차감하지 않으며, 이 모델은 대회용으로 임시 제공한다고 설명했다. 공식 가이드의 참가자당 한도는 분당 요청 100회·토큰 10만 개이며 수요에 따라 달라질 수 있다. [고정 체크리스트](https://discord.com/channels/1085960591052644463/1572294969522389133/1572294969522389133) · [크레딧 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1572314457164611697) · [임시 제공 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1573107348761874534) · [공식 가이드](https://docs.google.com/document/d/1Vvf2SjScBt3yBeTVZRoKtOyE7rGEP-gWV_ApzwXepEQ/edit)
- **사전 테스트.** 운영진은 개막 전 GPT OSS 120B나 Qwen으로 연결을 점검할 수 있다고 했고, 별도 테스트 크레딧은 제공하지 않는다고 답했다. API 키 발급에는 카드 확인이 필요하다고 정정했으며, 직불카드도 가능하다고 답했다. [사전 테스트 안내](https://discord.com/channels/1085960591052644463/1572153797390770186/1572390861017321635) · [테스트 크레딧 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1572848808855867395) · [카드 확인 정정](https://discord.com/channels/1085960591052644463/1572153797390770186/1572320179734577234) · [직불카드 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1573056083377787053)
- **프로젝트 요건.** 제출 프로젝트는 OpenClaw를 통해 Cerebras를 사용해야 한다. 기존 프로젝트를 확장해도 되며, 운영진은 Cerebras 적용 전후에 사용자 경험이 어떻게 달라지는지 보여 달라고 했다. 혼자 참가할 수 있고, 팀을 찾는 글은 해커톤 채팅에 올라와 있다. [OpenClaw 사용 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1572570065046601771) · [기존 프로젝트 허용 답변](https://discord.com/channels/1085960591052644463/1572153797390770186/1572819284118212730) · [고정 체크리스트](https://discord.com/channels/1085960591052644463/1572294969522389133/1572294969522389133)

## 데모와 제출

참가자가 RuneScape 에이전트 25개를 실행하는 초기 영상을 공유했다. 운영진은 원본 화면만 보면 Cerebras와 Kimi가 무엇을 바꾸는지 알기 어렵다며, **진행 상태나 완료한 작업을 화면에 표시하고 60초 이내로 편집**하라고 조언했다. 다른 서비스의 공시 TPS와 토큰 로그로 진행도를 비교하겠다는 아이디어는 참가자 제안이다. 별도 참가자가 보고한 속도 개선도 공식 벤치마크로 검증된 수치는 아니다. 그 참가자의 추가 접근 문의에 운영진은 전용 엔드포인트 영업 창구를 안내했다. [초기 데모](https://discord.com/channels/1085960591052644463/1572293043984531486/1572906219977310290) · [운영진의 영상 피드백](https://discord.com/channels/1085960591052644463/1572293043984531486/1572961314358173728) · [참가자의 비교 제안](https://discord.com/channels/1085960591052644463/1572293043984531486/1572973533913555048) · [전용 엔드포인트 답변](https://discord.com/channels/1085960591052644463/1572293043984531486/1572662054182068324)

공식 프로젝트 제출은 **X에 60초 이하 데모와 프로젝트명, 팀원 핸들, 2~4문장 설명**을 올리고 `@Cerebras`, `@Kimi_Moonshot`, `#KimiOnCerebras`를 포함하는 방식이다. 영상에 API 키나 개인정보가 보이지 않게 한다. GitHub 링크는 권장 사항이다. Reddit 상금에 응모하려면 r/cerebras에 `Kimi K3.1 Pro Hackathon` 플레어로 추가 게시한다. [공식 가이드](https://docs.google.com/document/d/1Vvf2SjScBt3yBeTVZRoKtOyE7rGEP-gWV_ApzwXepEQ/edit) · [Discord 제출 체크리스트](https://discord.com/channels/1085960591052644463/1572294969522389133/1572294969522389133)
