## 공식 규칙

주최 측 고정 글의 **Santa’s Speedy Shopper**는 가장 빠른 토큰 생성 속도를 기록한 참가자에게 **미화 1,000달러**를 지급하는 바운티다. OpenClaw에서 Cerebras의 Kimi K3.1 Pro를 사용해 실제 쇼핑몰의 크리스마스 선물 5개를 찾는다. 데모에는 온라인에 실제로 존재하는 상품 5개와 각각의 상품 상세 링크가 보여야 한다. 가상 상품과 하드코딩한 결과는 실격이다. [포럼 고정 규칙](https://discord.com/channels/1085960591052644463/1573839018964029450/1573839018964029450)

- **측정과 영상.** 공식 OpenClaw 속도 패치로 측정한다. 60초 이하 영상에 최고 TPS와 실제 상품 링크 5개를 보여준다. 고정 글의 TPS 정의는 **(출력 토큰 수 − 1) ÷ (마지막 토큰 시각 − 첫 토큰 시각)**이다. 공식 패치의 제출 안내는 게시글에 화면의 `mean tok/s`를 적으라고 명시한다. [공식 패치 제출 안내](https://github.com/wkasekende/openclaw-speed-patch/blob/e40e9f7b7ec41ad3fa68181ad297db119e755171/README.md#entering-the-speed-bounty) · [Cerebras의 TPS 정의](https://www.cerebras.ai/glossary/what-are-tokens-per-second)
- **제출글.** Discord `#share-your-demo`에 프로젝트명, 팀원 X 또는 Reddit 핸들, 2~4문장의 프로젝트 설명, 60초 이하 영상, 본문 TPS를 포함한다. GitHub 저장소 링크는 권장 항목이다. 고정 글에는 마감이 11월 22일 오후 6시로 적혀 있으며 시간대는 생략돼 있다. 질문은 고정 글의 스레드에서 받는다. [포럼 고정 규칙](https://discord.com/channels/1085960591052644463/1573839018964029450/1573839018964029450) · [제출 포럼](https://discord.com/channels/1085960591052644463/1573838301486387380)
- **공개 데모.** 속도 패치는 바운티 제출용이다. 주최 측은 X와 Reddit에 공개할 데모를 표준 OpenClaw로 녹화하라고 명시한다. [포럼 고정 규칙](https://discord.com/channels/1085960591052644463/1573839018964029450/1573839018964029450)

## 영상 교체 확인 범위

Discord API 문서는 메시지 수정 시 첨부 파일을 교체하는 기능을 설명한다. 일반 사용자를 위한 포럼 FAQ는 첫 글에 썸네일이 없고 작성자가 첫 답글에 미디어를 올릴 때 사용할 수 있는 기능을 안내한다. 게시된 제출글에 첨부 파일 수정 메뉴가 표시되며, 웹 화면에서 새 MP4로 교체하는 동작은 아직 확인하지 않았다. [Discord 메시지 수정 문서](https://docs.discord.com/developers/resources/message#edit-message) · [Discord 포럼 FAQ](https://support.discord.com/hc/en-us/articles/6208479917079-Forum-Channels-FAQ)
