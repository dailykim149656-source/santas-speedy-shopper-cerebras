# 첫 호출 도구 선택 방식 교차 비교

기본 D5027 세션의 첫 요청에 `tool_choice="required"` 하나를 적용하면 첫 호출의 추론 시간이 줄고, 다섯 상품을 실시간 조회한 세션의 평균 TPS가 오르는지 확인한다. 단일 유효 세션 1,500 TPS 초과를 기록 목표로 둔다.

| 조건 | 첫 요청 | 도구 조회 후 요청 |
|---|---|---|
| A | 기본 `auto`, 본문 그대로 전달 | 본문 그대로 전달 |
| B | `auto`를 `required`로 변경 | 본문 그대로 전달 |

같은 버전의 중계, 시스템 지시, 도구 정의, 온도 0.2, 낮은 추론, 출력 상한 1,024를 쓴다. 두 조건 모두 정상 완료 뒤 60초 대기하고 429 재시도·실패 후 대기는 기존 정책을 따른다. 별도 30초·60초 비교가 끝난 뒤 시작한다.

## 실행 수와 중단 기준

- 탐색은 **8쌍, 16회 전송**이다. A와 B를 8회씩 쓰며 인접한 두 실행의 순서는 AB, BA를 번갈아 배정한다. 특정 시각의 혼잡이 한쪽 조건에 몰리는 것을 줄이기 위한 순서다.
- 429 종료, 상품 검증 실패, 한 호출만 생성된 실행도 배정 횟수와 완료율 분모에 남긴다. 실제 전송 전에 종료됐다고 증명된 시도만 같은 배정으로 다시 준비한다. 한 쌍에서 양쪽 모두 유효해야 그 쌍의 TPS 차이를 계산한다.
- 재확인으로 넘어가려면 완전한 쌍이 4개 이상이고, 그중 75% 이상에서 B가 세션 평균을 높여야 한다. 첫 호출 TPS도 과반의 쌍에서 높아야 하며, 쌍별 세션 평균 차이(B−A)의 중앙값은 +50 TPS 이상, B의 유효 완료 횟수는 A 이상이어야 한다. +50은 운영상 더 조사할 가치가 있다고 정한 폭이다.
- 이 기준을 통과할 때만 **4쌍을 추가해 최대 24회** 전송한다. 재확인은 독립된 4쌍(BA, AB, BA, AB)에서 유효 쌍이 3개 이상, 세션 평균 B 승리가 3쌍 이상, 중앙 차이가 양수, B 유효 횟수가 A 이상인지를 본다. 탐색·재확인 결과를 각각 보고한다. 표본이 적어 효과의 크기나 재현 빈도를 확정하는 통계 검정으로 해석하기 어렵다.
- 마감 또는 공식 평균 1,500 초과와 상품·원본·영상 검증 완료가 먼저 도달하면 그때까지의 전송을 모두 보고한다. 16회에서 유효 쌍이 4개 미만이면 판정은 자료 부족이다.

각 실행의 첫·최종 TPS와 추론 토큰, 제공사 생성 시간, 캐시 읽기, 상품 검증, 429 횟수, 세션 평균을 비교한다. B 첫 요청은 받은 본문과 전달한 본문의 해시·필드 차이를 남기고, 도구 조회 뒤 요청은 받은 바이트와 전달한 바이트가 같은지 확인한다. [실행별 기록](<D5027-1500-실행기록.md>) · [비교를 제안한 근거](<D5027-1500-원인분석.md>)
